# Sportify.Setup

The Inno Setup installer of Sportify: `Sportify.iss`, its license text, the launcher scripts, the user guide and the sources of the library that is installed next to the add-in.
Built by `Sportify.Setup\Build-Installer.ps1` (called by `BuildDistribution.ps1` and by the release workflow); see `RELEASING.md` at the root of the repository.
