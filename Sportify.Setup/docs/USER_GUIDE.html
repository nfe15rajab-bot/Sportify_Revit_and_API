What Sportify does

Sportify helps you design sports and gardens on a roof. You design the layout in the web app (fields, gardens, furniture, structure), send it to Revit where it becomes real model elements, and check it with analyses (fire, carbon, accessibility, structure, sun and shade, wind, rain, dynamic loads, ball paths). From the results, Kinetics places moving elements (louvres, screens, sails, roller fences) and can build them as a mechanism in SOLIDWORKS. Everything you produce is collected in your Sportify folder.

Beta. Sportify is still under testing. Its results are preliminary and are not a substitute for the checks of a qualified architect or engineer.

1. What you need

NeededWhy
Windows 10 or 11 (64-bit) and Autodesk Revit 2025The add-in is built for Revit 2025.
Google Chrome (recommended)To use the web app on its own. Without Chrome your default browser is used.
About 600 MB of disk spaceThe add-in, the web app, the local database service and the library.

Optional: Unity (for the analysis videos, otherwise you get the charts as PDF) and SOLIDWORKS (for the Simulate button in Kinetics). Setup installs everything else itself: the web app, its local API and database, and the Microsoft components they need (WebView2 and the Visual C++ runtime, if your computer does not have them yet).

2. Install

  1. Close Revit. Double-click Sportify-Setup-{{VERSION}}-Revit2025.exe. Windows may show a blue “protected your PC” screen because the file is not code-signed yet: click More info, then Run anyway.
  2. License agreement: read it, choose I accept the agreement, click Next.
  3. Install folder: keep the suggested folder or choose another one you can write to (not Program Files), click Next.
  4. Your Sportify folder (deliverables): choose where your layouts, charts, videos, reports and schedules go. The suggestion is Documents\Sportify Workspace. Click Next, then Install.
  5. Wait while Sportify is installed. Setup copies the add-in, the web app and its API, the library, registers the add-in with Revit (you never copy a DLL yourself), installs missing Microsoft components and starts the local API once so that its database is ready.
  6. Finish: keep Open the Sportify web app ticked to see it in Chrome right away. If you would rather have it inside Revit, untick it and tick Open Revit with the web app docked inside it.
If an older Sportify add-in from June is found, setup offers to switch it off: say yes, otherwise Revit shows the error “The name already exists” at every start.

3. First start in Revit

  1. Start Revit 2025. Revit asks about an add-in from an unknown publisher (Sportify is not code-signed yet). It shows Digital Tools and Methods – Group of Sports and Gardens. Choose Always Load.
  2. A new tab called Sportify appears in the ribbon with six panels: App & Data Import, Algorithmic Analysis, Simulation & Analytics, Kinetics, BIM & Documentation and Data Export / Deliverables.
  3. Open a project. For a first try, a project with a roof (or a simple floor slab standing for it) is enough.

4. Guided walkthrough: your first roof

Step 1 · Open the web app

Either use the shortcut Sportify web app in the Start menu (opens in Chrome, works with Revit closed), or click Open Sportify App in Revit (opens docked inside Revit). Both are the same app.

Step 2 · Give it your roof

In Revit select the roof (or slab) and use Push to Sportify → Everything. The outline, structure, entries, openings and edges reach the web app. To switch to a different roof later use Push to Sportify → Update. You can also start in the web app without Revit and give it a roof of your own size, then bring Revit in later.

Step 3 · Design the layout

In the web app: Site (place, orientation), Structure (grid, columns, deck capacity), Sport (fields and their variants), Garden (parcels and build-ups), then Combine to put everything on the roof. The algorithmic placement mode suggests a layout you can adjust. Save your work with Save Session (top bar).

Step 4 · Send the layout to Revit

In the web app use Export Combined JSON in Combine. In Revit click Import Configuration (panel App & Data Import): the fields, gardens and furniture are built as elements, on worksets Sports, Gardens and Combine. Families the project does not have yet are made for you (or load your own with Load Families).

Step 5 · Run the analyses

Panel Algorithmic Analysis: fire safety, carbon impact, life-cycle, accessibility. Panel Simulation & Analytics: structure (bay utilisation, dynamic frequency), environment (sun and shade, wind uplift and erosion, soil percolation, ball trajectory). Each command asks whether you have Unity (a video) or not (charts as PDF). Send All to Web App puts every result in the web app’s Analysis tab.

Step 6 · Look at the results and improve

In the web app, Analysis lists every result, marks what is preliminary and which inputs are still default values. Compare puts up to three saved layouts side by side. Post Analysis shows where to improve the design and what Kinetics placed.

Step 7 · Kinetics: moving elements from the analysis

  1. Generate Family once per project (makes the two adaptive families every moving unit is built from).
  2. Import Analysis Adaptation: choose what to make – overhead louvre, slat screen, fin screen (select a wall or railing first), tensile sail on movable masts, roller fence. Kinetics uses the sun analysis to decide the number and spacing of blades and how the unit moves through the day, and places it as adaptive components (moving parts on the worksets Sportify Dynamic Furniture and Structure).
  3. Record Isolated Video (needs Unity) and Simulate (SOLIDWORKS) (needs SOLIDWORKS) make a film of the unit moving; the SOLIDWORKS assembly and a STEP file go to the Mechanical folder of your Sportify folder.

Step 8 · Documents for the project

Panel BIM & Documentation: Generate Schedules, Apply View Filters, and the Phasing & Worksets drop-down. Panel Data Export / Deliverables: Analysis Report (PDF), Functional Diagrams, Schedules (CSV). Open Sportify Folder shows everything in one place.

6. The library

Setup also puts a Library folder in the install folder (Start menu: Sportify library):

FolderWhat is in it
TemplatesRevit project templates Sportify_EN.rte and Sportify_DE.rte (view templates, sheets, schedules). Start a project with File → New → Project → Browse.
FamiliesThe Revit families Sportify uses (fields, sports equipment, garden parcels, adaptive families). Load them with Insert → Load Family, or point Revit’s File Locations → Places at this folder.
WorksetsThe list of Sportify worksets and phases (what each holds), as a sheet and as data.
DocumentationThis guide, the license agreement, and notes on the Sportify folder and on the Revit–SOLIDWORKS bridge.
DatabaseNotes on the reference database (sport fields, build-ups, materials, prices). It is created by the local API the first time it runs.

7. If something does not work

What you seeWhat to do
No Sportify tab in RevitClose Revit, run setup again and accept the offer to switch off the old add-in; check that Revit 2025 (not another year) is the one you start.
“The name already exists” at Revit startAn older Sportify add-in is still installed. Setup can switch it off (it renames Sportify.addin in %APPDATA%\Autodesk\Revit\Addins\2025 to .disabled).
“Revit cannot run the external application Sportify… HttpListenerException”Another program uses one of Sportify’s local ports (5679, 8123). Close it and restart Revit.
The web app in Chrome shows no catalogueUse the Start menu shortcut Sportify web app (it starts the local API first) and wait a few seconds.
The docked web app pane is emptyMicrosoft WebView2 is missing: run setup again with internet access, or use the web app in Chrome.
Windows warns about the setup fileSportify is not code-signed yet: More info → Run anyway.

8. Uninstall

Settings → Apps → Sportify → Uninstall (or the Start menu entry). It removes the add-in, the web app, the API and the library. Your Sportify folder with your own files is kept unless you choose to delete it.
