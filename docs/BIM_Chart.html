Sportify BIM Chart

How the Sportify add-in organises a Revit model: which phase, design option and workset each element goes to, how it is drawn (colours, line weights, view templates), and on which A0 sheet it ends up. Like a plot-style table (CTB), it is the one reference for the drawing standard. Every value is the add-in's own; the source file is named in each section.

1PhaseWhat exists, what is designed, what the analyses add afterwards.
2Design optionThe garden iterations side by side: planter, quiet, social.
3WorksetWhat a person wants to isolate or hide: sports, gardens, furniture, annotation, analysis.
4GraphicsFilters, overrides and the "Diagrams" template: colour, line weight, halftone.
5Sheets & tagsSix A0 plan sheets in a fixed order, then the lists; every piece tagged with Tag_Sportify.

01 Phases SportifyPhases.cs, SportifyLayoutBuilder.cs

PhaseWhat is in itShown on
Existing
the project's first phase, whatever its name		The building and the roof as they stand (Goldbeck / IFC model).S2-01 Roof existing (the roof new plan, duplicated, in this phase; Sportify pieces hidden)
Design and analysisEverything an import from the web app brings: courts, activities, garden build-ups, planting, furniture, walls of the indoor zone, paths and entries.S2-02 Roof new, S2-03 axonometric, the diagrams
Post analysisWhat the analyses ask for afterwards: the dynamic furniture Kinetics places from their results.S2-02 Roof new (it shows the newest phase)

Revit's API can neither create nor rename a phase. Set Up Phases & Worksets finds the phases a project has, says which one stands for which, and opens Manage > Phasing for the renaming.

02 Design options IterationCommands.cs, RoofMatch.cs, ImportLedger.cs

Option set "Garden iterations"HoldsFilled by
Option 1 planter primaryThe planted iteration (High Roof Garden, planted).Import Iterations, with that option being edited (Design Options bar at the bottom of Revit). The iteration whose name matches the option's is chosen for you.
Option 2 quietThe quiet iteration.
Option 3 socialThe social iteration.
RuleWhat Sportify does
Making optionsA person makes the set and its three options once (Manage > Design Options): Revit's API cannot create, name or activate an option.
Import into an optionEvery piece lands in the option being edited. Fewer than half landing there: the import is undone. An option that already holds another iteration: asked before it is replaced.
Main modelHolds the current design (the last Sync with Revit). Syncs, Remove Duplicates and Clear this roof never touch an option's content; a sync is refused while an option is being edited.
LedgerEach import is recorded in the project (Extensible Storage), keyed by its roof or by option:<id>, so a re-import replaces exactly its own pieces.

A project that is not workshared keeps everything on its one workset; the worksets are made when missing, never renamed. "Organize Multi-Worksets" puts an element back where the import put it.

RuleWhat Sportify does
SizeEvery sheet on the German Plankopf (Ausführung; Genehmigung for phase 3) in its A0 type, 1189 × 841 mm. A sheet on another size is switched to A0; its lists stay at the top left, its views are centred left of the title block.
OrderNumbered in the order above. A sheet is recognised by what it shows first, then by its name (this template's or the earlier one's), then, when empty, by its number: a person's own content is kept.
WhenApply Sportify Template (German or English) and every drawing of the diagrams (any analysis, Generate Functional Diagrams): a diagram goes on its sheet as soon as it exists; the active roof's diagram replaces an older one on its sheet.
BrowserFiled under "Sportify" (Projektbrowser Plangliederung) and phase 2-Entwurf (Projektbrowser Leistungsphase).

The chart describes the add-in as it is on 2026-09-30. Three things are a person's to do once per project, because Revit's API cannot: make the phases' names right (Manage > Phasing), make the design option set and its options (Manage > Design Options), and pick which option is primary.
