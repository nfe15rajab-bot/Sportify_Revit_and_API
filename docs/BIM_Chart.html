Sportify BIM Chart

How the Sportify add-in organises a Revit model: which phase, design option and workset each element goes to, how it is drawn (colours, line weights, view templates), and on which A0 sheet it ends up. Like a plot-style table (CTB), it is the one reference for the drawing standard. Every value is the add-in's own; the source file is named in each section.

1PhaseWhat exists, what is designed, what the analyses add afterwards.
2IterationsThe three garden iterations side by side: one workset and one view each; design options once a person fills them.
3WorksetWhat a person wants to isolate or hide: sports, gardens, furniture, annotation, analysis.
4GraphicsFilters, overrides and the "Diagrams" template: colour, line weight, halftone.
5Sheets & tagsSix A0 plan sheets in a fixed order, then the lists; every piece tagged with Tag_Sportify.

Revit's API can neither create nor rename a phase. Set Up Phases & Worksets finds the phases a project has, says which one stands for which, and opens Manage > Phasing for the renaming.

RuleWhat Sportify does
One iteration per viewIts own iteration, the default layout's garden and the rest of the model. The other iterations and the main model's copy of the iterated roof's garden (the last synced design, one of the iterations) are hidden.
Design optionsRevit's API cannot create, name, activate or fill an option; Import Iterations as Design Options fills the one being edited. The submitted model keeps the iterations on worksets.
Main model, ledgerThe main model holds the current design (the last Sync). Each import is recorded in the project, keyed by its roof or option:<id>, so a re-import replaces exactly its own pieces; Remove Duplicates never takes an iteration's piece for a duplicate.

RuleWhat Sportify does
SizeEvery sheet the add-in makes is on the project's own Sportify Plankopf (else the German one) in its A0 type, 1189 × 841 mm, its views centred left of the title block. A sheet a person resized keeps its size.
OrderNumbered in the order above. A sheet is recognised by what it shows first, then by its name (this template's or the earlier one's), then, when empty, by its number: a person's own content is kept.
WhenApply Sportify Template (German or English) and every drawing of the diagrams (any analysis, Generate Functional Diagrams): a diagram goes on its sheet as soon as it exists; the active roof's diagram replaces an older one on its sheet.
BrowserFiled under "Sportify" (Projektbrowser Plangliederung) and phase 2-Entwurf (Projektbrowser Leistungsphase).

Model checks

What makes the Goldbeck model a BIM model and not a drawing, and where the submitted model stands. The checks are run by the Sportify model inspector (Sportify.ModelInspect, BimAudit.cs) on a copy of the project: it only reads. Audit of 2026-10-01 on the final model's content: 27 checks passed, 4 warnings, 3 open.
